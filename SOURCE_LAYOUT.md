# Source layout

## `WinUI2/API`

Core Delphi wrappers for the WinUI 2/XAML Islands implementation.

## `WinUI3/API`

Core Delphi wrappers for the WinUI 3 / Windows App SDK implementation.

## Login demos

The `Login.Auth`, `Login.View`, `Login.Pages` and `Login.Xaml` units are samples built on top of the framework APIs. They are not required by the framework itself.

## `Samples`

Contains the WinUI 3 calculator sample and its calculation engine.
